# Project memory

Durable decisions and context for this repo, checked in so every teammate (and every
Claude Code session) starts with the same knowledge. One file per fact.

This is the **project-scoped** counterpart to a personal `~/.claude` memory: nothing here
is user-specific, and everything here should still be true in six months.

| File | What it records |
|---|---|
| `storage-seam.md` | Why `StorageAdapter` exists and the rule that protects it |
| `content-pipeline.md` | How the question banks are generated and validated |
| `topic-taxonomy.md` | Why topics are split the way they are |
| `source-materials.md` | Where the content came from and what is deliberately not committed |

Add a file when a decision would otherwise have to be re-derived from the diff.
